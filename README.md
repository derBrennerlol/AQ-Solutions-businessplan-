## Projektplanung & Aufgaben

Unsere Planung läuft über das GitHub Project:
👉 [AQ Solutions – Planung](LINK-ZUM-PROJECT)

**So arbeiten wir:**
1. Jede Aufgabe ist ein Issue (Vorlage nutzen) und bekommt eine verantwortliche Person.
2. Neue Issues landen im **Backlog**. Im wöchentlichen Treffen priorisieren wir und schieben sie nach **Ready**.
3. Wer eine Aufgabe startet, setzt sie auf **In Progress** und legt einen Branch an (`feature/kurzname`).
4. Fertig → Pull Request mit `Closes #<Issue-Nummer>`, Status **Review**.
5. Mindestens eine weitere Person reviewt, dann wird gemerged und das Issue schließt sich automatisch (**Done**).

**Ansichten:** Board (Tagesgeschäft), Tabelle (Filter nach Person/Phase), Roadmap (Zeitplan bis zur Abgabe).
